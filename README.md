# shivatakshi-4-ai-nepal

A bilingual Nepali-English coding and AI learning space for Shivatakshi students. / शिवताक्षीका विद्यार्थीहरूका लागि नेपाली र अंग्रेजीमा कोडिङ तथा AI सिक्ने साझा स्थान।

This repository is a static landing page for a learning community focused on coding, AI literacy, creativity, and safe digital habits. It is designed for students who want to learn in Nepali, English, or both.

## Project status

- Type: static website
- Primary language: HTML
- Styling: plain CSS in the same file
- Framework: none required
- Deployment target: Vercel

## Run locally

Because this is a static site, you can open the project in a browser without installing dependencies.

```bash
# Open the project directly in a browser
open index.html
# or on Linux
xdg-open index.html
# or double-click index.html in a file explorer
```

## Deploy on Vercel

This repo is ready to deploy as a static site.

1. Go to https://vercel.com
2. Click "Add New Project"
3. Import this GitHub repository
4. Use the default settings
5. Keep the framework as "Other" or leave it unset
6. Set the root directory to the repository root
7. Do not set a build command for this simple static HTML site
8. Set the output directory to the root or leave blank if Vercel detects `index.html`
9. Click "Deploy"

Vercel will publish the site and redeploy automatically whenever you push changes to the connected branch.
